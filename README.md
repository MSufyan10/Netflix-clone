# 🎬 Netflix Clone - Frontend Project

**Live Demo:** https://netflix-clone-rho-three-49.vercel.app
**Repo:** https://github.com/MSufyan10/Netflix-clone

> ⚠️ **EDUCATIONAL DISCLAIMER:** This is a frontend UI clone built for learning HTML, CSS & video backgrounds. It is NOT the real Netflix. Not affiliated with Netflix, Inc. No login, no streaming, no data collection.

### 📸 Preview
Netflix-inspired landing page with background image, video section, FAQ, and responsive layout — just like the real Netflix homepage.

### ✨ Features
- Netflix-style hero section with background image `bg.jpg`
- Navigation with logo `logo.svg`
- Auto-playing background video `video1.m4v`
- Email input + Get Started button (UI only)
- Trending / Features section
- FAQ accordion style section
- Fully responsive for mobile & desktop
- Footer links

### 🛠️ Built With
- **HTML** - `index.html`
- **CSS** - `netflix.css` (Flexbox, Positioning, Media Queries)
- **Assets:** `bg.jpg`, `logo.svg`, `video1.m4v`, `favicon.ico`
- **Hosting:** Vercel
