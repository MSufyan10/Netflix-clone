### 📸 Preview
Netflix-inspired landing page with background image, video section, FAQ, and responsive layout — just like the real Netflix homepage.

### ✨ Features
- Netflix-style hero section with background image 
- Navigation with logo 
- Auto-playing background video 
- Email input + Get Started button (UI only)
- Trending / Features section
- FAQ accordion style section
- Fully responsive for mobile & desktop
- Footer links

### 🛠️ Built With
- **HTML** - `index.html`
- **CSS** - `netflix.css` (Flexbox, Positioning, Media Queries)
- **Assets:** `bg.jpg`, `logo.svg`, `video1.m4v`, `favicon.ico`
- **Hosting:** Vercel
